Query

Everything on this site is also linked data, which you can search with SPARQL queries here. The queries run in your browser, using Oxigraph. Start from one of the examples, or write your own.

The data is in three parts, which a query sees together. You can also ask for one at a time with GRAPH, or download them:

  • wkw.ttl: Who Knew Whom’s own data. Everyone is a foaf:Person with a foaf:name, and foaf:knows links each person to the people they knew. There are also dates and places (schema:birthDate, wkw:birthPlaceText and so on), professions (schema:hasOccupation), bios (dcterms:description), sources, and the matching Wikidata item (owl:sameAs).
  • supplement.ttl: dates and places of birth and death that Who Knew Whom doesn’t give, taken from Wikidata, in the same terms.
  • wikidata.ttl: what Wikidata says about the same people, in Wikidata’s own terms (wdt:P569 for date of birth, wdt:P18 for a picture and so on), so queries written for query.wikidata.org work here too.
